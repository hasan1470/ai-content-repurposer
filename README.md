# Recast AI

Recast AI is a responsive content repurposing workspace that turns one article or video transcript into channel-ready social posts, email newsletters, summaries, and a seven-day content calendar.

## Features

- Article and video transcript input modes
- Plain-text file importing and drag-and-drop support
- Professional, conversational, bold, and educational tones
- Audience targeting controls
- LinkedIn post generation
- X thread generation
- Email newsletter generation
- Executive summary generation
- Instagram caption generation
- Editable output workspace
- Copy and text export actions
- Seven-day cross-channel content calendar
- Local project saving
- Responsive desktop and mobile interface

## Getting Started

Install the dependencies and start the development server:

```bash
npm install
npm run dev
```

Open the local URL displayed in the terminal.

## Available Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Create a production build |
| `npm run start` | Start the production server |
| `npm run lint` | Run ESLint |

## Privacy

The current version processes source material in the browser. Saved projects use browser storage and are not uploaded to a remote server.
